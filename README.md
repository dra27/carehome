# Maintenance scripts for OCaml opam packaging

Various scripts and `Dockerfile`s used for testing and maintenance of the OCaml
compiler's opam packages ([ocaml-base-compiler](https://opam.ocaml.org/packages/opam-base-compiler/),
[ocaml-compiler](https://opam.ocaml.org/packages/opam-compiler/),
[ocaml-variants](https://opam.ocaml.org/packages/opam-variants/), etc.)
